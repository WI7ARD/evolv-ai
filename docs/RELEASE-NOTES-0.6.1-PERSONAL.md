# Evolv Personal 0.6.1 Release Notes

Evolv 0.6.1 introduces a new futuristic green circuit-board identity across the desktop executable, lock screen, sidebar, mobile header, and chat welcome view.

The main circuit core now idles with restrained trace and halo motion. During text-to-speech, the circuit expands, brightens, and energizes only after system speech or Piper audio actually begins playback. It returns to idle when playback ends, pauses, errors, or is stopped. Reduced-motion preferences disable continuous animation while preserving a subtle speaking-state indicator.

This is a visual and voice-feedback update to the private Evolv build. It does not change provider permissions, tool permissions, account isolation, the Goal Runner approval policy, or the published itch.io release.
