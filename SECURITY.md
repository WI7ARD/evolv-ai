# Security policy

Evolv is a localhost-only desktop application. Do not include API keys, passwords, recovery codes, profile databases, Obsidian vault contents, logs, or exports in GitHub issues.

Report a security issue privately through GitHub's private vulnerability reporting feature after the repository is published. Include the affected version, reproduction steps, and impact without attaching private user data.

Only the latest stable Windows release receives security fixes. Release ZIPs must be accompanied by the exact `.sha256` asset generated by the release workflow. The in-app updater rejects prereleases, redirects outside trusted GitHub hosts, missing checksums, checksum mismatches, incorrect versions, and invalid packaged-file integrity manifests.

Windows builds remain unsigned until a code-signing certificate is configured. Users should expect SmartScreen warnings until signing is completed.
